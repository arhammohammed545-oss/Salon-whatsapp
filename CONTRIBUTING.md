# Contributing

Thank you for considering a contribution.

## Before opening a pull request

- Discuss substantial changes in an issue first.
- Keep changes focused and include a clear description.
- Add or update tests when behavior changes.
- Run `npm run typecheck` and `npm run build`.
- Use synthetic data only. Never include customer information, access tokens, credentials, or production exports.
- Do not enable live WhatsApp sending without explicit consent checks, approved templates, and appropriate tests.

## Pull requests

Explain the problem, the proposed solution, and how you tested it. Include screenshots only when they contain no personal or confidential information.
